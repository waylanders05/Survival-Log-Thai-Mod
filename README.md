# Survival Log — Thai Fan Translation

มอดภาษาไทยสำหรับเกม **Survival Log** บน Steam

รุ่นล่าสุด: **1.0.14911**

## ดาวน์โหลด

ดาวน์โหลดไฟล์ `Survival_Log_Thai_1.0.14911.zip` จากหน้า [Releases](../../releases)

## ติดตั้งแบบง่าย

1. ปิดเกมให้สนิท
2. แตกไฟล์ ZIP
3. ดับเบิลคลิก `Install-ThaiMod.cmd`
4. เปิดเกมใหม่ แล้วเลือกภาษา `ไทย (ต้นแบบ)`

ตัวติดตั้งจะค้นหาโฟลเดอร์เกมจาก Steam Library ให้อัตโนมัติ หากหาไม่พบจะเปิดหน้าต่างให้เลือกโฟลเดอร์เกมเอง

## ถอนการติดตั้ง

ดับเบิลคลิก `Uninstall-ThaiMod.cmd` ในโฟลเดอร์ที่แตกไฟล์ไว้

มอดนี้แปลเมนู ระบบ ไอเทม ตัวละคร ความยาก เหตุการณ์ เนื้อเรื่อง บทสนทนา และข้อความระหว่างเล่น โดยไม่แก้ไขเซฟเกม ตัวติดตั้งจะสำรองไฟล์เดิมก่อนแก้ไข

หากเกมอัปเดตผ่าน Steam ให้ติดตั้งมอดใหม่อีกครั้ง หากพบข้อความภาษาอังกฤษหรือการจัดวางผิดปกติ กรุณาเปิด Issue พร้อมภาพหน้าจอและระบุฉาก
